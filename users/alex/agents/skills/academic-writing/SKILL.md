# Academic writing

The owner is a clinical researcher. Writing tasks may include original research
papers, review articles, case reports, editorials, abstracts, grant sections,
or letters. Ask which type before starting — structure and conventions differ.

## Paper types and structure

### Original research (IMRaD)

- **Title**: specific, informative, no jargon abbreviations; state the design
  if relevant (e.g. "cohort study", "randomised trial")
- **Abstract**: structured (Background / Objectives / Methods / Results /
  Conclusions). Word limit is strict — never exceed it. Write it last.
- **Introduction**: 3–4 paragraphs. (1) What is the problem and why does it
  matter? (2) What is already known? (3) What is the gap? (4) What did this
  study do and why?
- **Methods**: reproducible without the authors. Include: study design, setting,
  population (inclusion/exclusion criteria), exposures/outcomes, follow-up,
  statistical analysis plan, software version, ethics/consent statement.
- **Results**: factual, no interpretation. Lead with the main finding.
  Tables and figures are primary — text should narrate, not duplicate them.
- **Discussion**: (1) Main finding in one sentence. (2) How it relates to prior
  work. (3) Mechanisms or explanations. (4) Strengths and limitations — be
  honest, not defensive. (5) Implications and future directions. (6) Conclusion.
- **Acknowledgements**: funding sources, data access, non-author contributors.
- **Conflicts of interest**: declare per journal policy.

### Review articles

Systematic reviews follow PRISMA. Narrative reviews are less constrained but
still need a clear structure. Define scope explicitly — what is and isn't covered.

### Case reports

Brief introduction → case description (enough detail to reproduce the clinical
reasoning) → discussion (why is this case notable? what does it add?). Check
CARE guidelines for completeness.

### Letters to the editor

Concise (usually 400–600 words). One main point. No tables. Reference the
specific article being commented on.

## Writing principles

**Clarity over complexity.** One idea per sentence. Active voice where possible.
Avoid nominalisations ("perform an analysis of" → "analyse").

**Precision.** Numbers need units. Rates need denominators. "Significant" means
statistically significant — don't use it loosely.

**Consistency.** Abbreviations: define at first use, then use consistently.
Do not switch between synonyms for the same concept (e.g. "patients" vs.
"subjects" vs. "participants" — pick one).

**Tense conventions:**
- Methods and results: past tense (what you did and found)
- Introduction and discussion references to established facts: present tense
- Your own prior work cited as background: present tense

## Editing workflow

When asked to edit a draft:
1. Read the full section before changing anything.
2. Identify the main structural issue (if any) before fixing language.
3. Edit for clarity and concision — cut without losing meaning.
4. Flag but do not fix: statistical claims, numbers, references (the owner
   must verify these).
5. If the section is missing a key component (e.g. limitations in discussion),
   point it out rather than inventing content.

Return the edited text with brief notes on what changed and why, so the owner
can accept or reject decisions.

## Cover letters

Structure:
1. One-sentence statement of what the paper is and its main finding.
2. Why this paper is a good fit for *this journal specifically* — not generic.
3. Why it will interest the journal's readership.
4. Confirmation of: not submitted elsewhere, all authors approved, no conflicts
   (or disclose them), ethical approval obtained.
5. Optional: suggest or exclude reviewers if the journal allows.

Keep it under one page. The editor reads dozens per day — be direct.

## Responding to peer review

This is often the most consequential writing in the publication process.

### General principles

- Thank the reviewers (briefly, once, sincerely).
- **Address every point**, even if you disagree. Ignoring a comment guarantees rejection.
- Quote the original comment, then your response, then the revised text (if applicable).
- Be specific: "We have added X to lines Y–Z of the revised manuscript."
- If you disagree with a reviewer: acknowledge their concern, explain your
  reasoning calmly, provide evidence or literature support. Do not capitulate
  on points where you are right — but pick your battles.
- Changes that improve the paper: make them even if not required.
- Changes that would harm the paper: explain why you did not make them.

### Format

```
Reviewer 1, Comment 1:
[Quote the comment verbatim]

Response:
[Your reply]

Revision:
[Paste the revised text, or state "no change to manuscript text"]
```

### Tracking changes

Most journals want a clean manuscript + a tracked-changes version. Keep both.
If you are preparing the response, also prepare the manuscript revision in sync.

## Journal selection

When the owner asks for journal suggestions:
- Ask: scope (clinical vs. basic), target audience, open access requirement,
  IF preference, whether there is a specific society journal to prioritise,
  turnaround time constraints.
- Do not recommend journals from memory — check the current scope and IFs
  via the journal website or PubMed. IFs change yearly.
- Predatory journals: check DOAJ (https://doaj.org) or Beall's list. If a
  journal is not indexed in PubMed/MEDLINE or Web of Science, flag it.
- ELA-relevant journals: Amyotrophic Lateral Sclerosis and Frontotemporal
  Degeneration (ALSFRS), Brain, Journal of Neurology Neurosurgery and Psychiatry,
  Annals of Neurology, European Journal of Neurology, Neurology.

## Formatting for submission

Before submitting:
- Read the author instructions for *this journal*, not a generic template.
  Word limits, reference style, figure format, and supplementary file policy
  vary and are enforced.
- Reference style: use the journal's required format. If Zotero is in use,
  check the references skill for how to export in the right style.
- Blinding: if double-blind review, remove author names and affiliations from
  the manuscript file, and strip metadata from Word/PDF files.
- File formats: most journals accept .docx for the manuscript. Figures are
  usually TIFF or EPS at 300 dpi (halftone) or 600 dpi (line art).

## Abstracts for conferences

Usually 250–350 words, structured. Submit well before the deadline — late
submissions are typically not accepted. Check whether the conference allows
simultaneous journal submission of the same work.
